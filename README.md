# Hogwarts Dash

**Hogwarts Dash** es un juego inspirado en el clásico Geometry Dash, pero reinventado en el mágico universo de Harry Potter. El proyecto está disponible para **Android** y **PC**, y ofrece una dinámica desafiante con vehículos/transformaciones mágicas y niveles temáticos.

---

## Características Principales

- **Vehículos mágicos:**  
  - **Cubo** → Cubo mágico  
  - **Bola** → Bola mágica  
  - **UFO** → Sombrero mágico  
  - **Cohete** → Escoba mágica

- **Niveles:**  
  - Supera **5 niveles únicos**, cada uno con obstáculos, mecánicas y ambientación inspirada en Hogwarts.

- **Menús:**  
  - **Cambio de skin:** personaliza tu vehículo con diferentes skins mágicos.
  - **Ajustes:** controla música, sonido, controles y adaptaciones para Android y PC.
  - **Selección de niveles:** elige y desbloquea los distintos niveles.

- **Plataformas:**  
  - **Android:** controles adaptados al móvil, interfaz simple y optimizada.
  - **PC:** controles clásicos y compatibilidad teclado/mouse/gamepad.

## Instalación

### PC

1. Clona el repositorio:
   ```bash
   git clone https://github.com/IgorESP/Hogwarts_Dash.git
   ```
2. Abre el proyecto en tu IDE preferido (Unity, Godot, etc., según cómo esté hecho).
3. Compila y ejecuta el juego.

### Android

1. Descarga el APK (si está disponible en releases).
2. Instala el APK en tu dispositivo Android.
3. Disfruta del juego.

---

## Gameplay

- Avanza por los niveles sorteando obstáculos con los vehículos mágicos.
- Usa tus habilidades de salto, transformación y vuelo para superar cada fase.
- Personaliza tu personaje y ajusta el juego a tus preferencias en los menús incluidos.
